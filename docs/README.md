# XControl documentation

One page per part of the app, in the order of the sidebar.

**Gaming**

- [Controllers](controllers.md): DualShock 4 and DualSense: light bar, report rate, Xbox 360
  emulation, remapping, touchpad gestures, gyro aiming, per-game layouts

**Hardware**

- [Power](power.md): idle sleep, power buttons and lid, power profile, screen power, keeping the
  screen on, battery and power alerts

**Desktop**

- [Wallpaper & Lock](desktop.md): wallpaper, screen lock, starting at login
- [Window Manager](window-manager.md): the generated i3 or Openbox config
- [Bar & Compositor](bar-and-compositor.md): polybar and picom
- [Notifications](notifications.md): dunst
- [Default Apps](default-apps.md): what opens which file type, and the terminal

**System**

- [Date & Language](date-and-language.md): time zone, clock, language and formats
- [Users](users.md): accounts, groups, pictures
- [About & Tools](system.md): system information, the boot splash (Plymouth), kernel modules, session check and backups
- [X server](x-server.md): loaded modules, X options, choosing the video driver
