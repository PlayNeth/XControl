# XControl documentation

One page per part of the app, in the order of the sidebar.

- [Displays](displays.md): layout, scaling and color, night light, custom resolutions, the

- [Input](input.md): mouse and touchpad, keyboard, gaming mice (libratbag)
- [Controllers](controllers.md): DualShock 4 and DualSense: light bar, report rate, Xbox 360

- [Sound](sound.md): renaming, hiding and keeping devices awake, PipeWire sample rate and buffer

- [Window Manager (i3)](window-manager.md): the generated i3 config
